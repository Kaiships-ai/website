Humanizer: make AI text sound like you

The install command and how to paste your own writing sample.

Humanizer is a free, open-source Claude skill (MIT) that makes AI-written text sound like a person wrote it, without changing what it says. It is built on Wikipedia's own guide, Signs of AI writing, and checks for 26 patterns.

What it catches

Five of the strongest tells it rewrites on sight: "not X but Y" ("It's not just a feature, it's a shift"), one-line closers ("Let that sink in"), sayings that sound deep ("At its core…"), a staged run-up ("Here's the thing", "Honestly?") and arguing with no one. Plus overused AI words like "delve" and dashes used everywhere: 26 patterns in all.

Install in Claude Code
/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer

Needs Claude Code 2.1.142 or newer. As a plugin it answers to /humanizer:humanizer.

Older Claude Code, or Codex
npx skills add blader/humanizer --global --agent claude-code  # older Claude Code
npx skills add blader/humanizer --global --agent codex        # Codex

Claude.ai or Claude Desktop: download the repo as a ZIP (Code → Download ZIP) and upload it as a skill in Settings.

Use it

Type /humanizer and paste your text, or point it at a file: Humanize the prose in docs/launch-post.md.

/humanizer
Here's a sample of my writing for voice matching:
[paste 2-3 paragraphs of your own writing]
Now humanize this text:
[paste AI text to humanize]

It follows your sample's rhythm, word choice, punctuation and quirks, including dashes if you use them. Use a sample from something you wrote before AI: an old post, an email, a note.

⚠️ What it's not. It edits for human readers. Getting past AI detectors is not its goal. It doesn't make up facts: if a sentence needs a detail you didn't give, it asks.
