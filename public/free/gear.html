4 free plugins to set up Claude Code

What each one does, and the install command from its own README.

Four free add-ons I'd put on a fresh Claude Code setup: memory between sessions, a way to find skills, a document reader, and Anthropic's own setup advisor.

Words on this page

Plain meanings, in case some of these are new.

Claude Code
Anthropic's AI assistant that works inside your terminal and your project files.
Terminal
The text window where you type commands (Terminal on Mac, PowerShell on Windows).
npx
Runs a JavaScript tool without installing it for good. Comes with Node.js.
Plugin
An add-on you install inside Claude Code with the /plugin command.
Skill
A packaged set of instructions an AI agent loads when a task needs it.
Token
The small chunk of text an AI reads and writes. Usage and limits are counted in tokens.
Hook
An action Claude Code runs automatically, like formatting a file after an edit.
Sub-agent
A helper agent Claude Code starts for one focused job, like a review.
MCP server
Model Context Protocol server: an add-on that gives your AI assistant extra tools.
README
The front-page instructions of a code project on GitHub.

The 4 plugins

memory

1. claude-mem

in one lineClaude Code remembers your past sessions.
What it does

Keeps memory across sessions, so a new chat starts with what you did before. Free and open source (Apache-2.0).

Install
npx claude-mem install

The installer asks you to sign in for a hosted free trial. To skip that, pass an explicit --provider flag (the README's way to install without an account).

Sourcegithub.com/thedotmack/claude-mem
find

2. find-skills (skills CLI by Vercel)

in one lineSearch an open library of skills and install the best ones.
What it does

The skills CLI searches the open skills library at skills.sh and installs a skill into your agent in one line.

Commands
npx skills find           # search interactively
npx skills find react     # or by keyword
npx skills add <package>  # install one
Sourceskills.sh
read docs

3. AnyDoc (Firecrawl)

in one linePowerPoint, Excel and Word files to clean markdown.
What it does

Turns office files into clean markdown, so Claude reads them with fewer tokens. Open source (MIT).

Install
npx skills add firecrawl/anydoc
Sourcegithub.com/firecrawl/anydoc
setup

4. Claude Code Setup (official Anthropic plugin)

in one lineScans your project and tells you what to add.
What it does

Scans your codebase and recommends hooks, skills, sub-agents and MCP servers for it. Read-only: it never edits your files.

Install (inside Claude Code)
/plugin install claude-code-setup@claude-plugins-official

Then ask: "recommend automations for this project".

Sourceanthropics/claude-plugins-official
