CLI-Anything: connect Claude Code to almost any software

The repo link, the 2 install commands and an example.

CLI-Anything (by HKUDS) is a free, open-source Claude Code plugin (Apache-2.0, 50,000+ stars on GitHub). Point it at an app's source code and it builds a command-line tool your agent can use, even for apps with no MCP.

It needs source code. Give it a repo or a local folder with the app's code. No code, no CLI.

What it does

Reads the app's source code, designs and builds the CLI commands, writes tests and docs, then installs the tool to your PATH.

Install (inside Claude Code)
/plugin marketplace add HKUDS/CLI-Anything
/plugin install cli-anything
Example
/cli-anything ./gimp                              # a local folder with GIMP's code
/cli-anything https://github.com/blender/blender  # or a repo link
What people point it at

Apps in the README include Blender, GIMP, Zoom, NotebookLM, Inkscape, Audacity, LibreOffice and OBS.
