5 plugins for vibe coding with Claude Code

What each one does, and the install command from its own README.

Five free add-ons that make vibe coding with Claude Code safer and faster: a browser it can test in, a database it can manage, a security tester, a design copier and fresh docs.

Words on this page

Plain meanings, in case some of these are new.

Vibe coding
Building an app by describing what you want to an AI and letting it write the code.
Claude Code
Anthropic's AI assistant that works inside your terminal and your project files.
Terminal
The text window where you type commands (Terminal on Mac, PowerShell on Windows).
npm / npx
Node.js tools: npm install -g installs a command for good, npx runs one without installing it.
Plugin
An add-on you install inside Claude Code with the /plugin command.
Skill
A packaged set of instructions an AI agent loads when a task needs it.
LLM API key
A personal key that lets a tool call an AI model (OpenAI, Anthropic and others). Usage is billed to you.
Design system
The colors, fonts, spacing and components that make a site look the way it does.
README
The front-page instructions of a code project on GitHub.

The 5 plugins

test

1. Playwright CLI (Microsoft)

in one lineYour AI opens a browser and checks what it built.
What it does

Lets Claude Code open real browsers, click through your app, take screenshots of what it built and catch errors.

Install
npm install -g @playwright/cli@latest
playwright-cli install --skills        # adds the skills Claude Code uses
Sourcegithub.com/microsoft/playwright-cli
database

2. Supabase plugin (official)

in one lineBuild and manage your app's database from the terminal.
What it does

Gives Claude Code Supabase skills and database access, so it can set up and manage your app's database, auth and storage for you.

Install (inside Claude Code)
/plugin install supabase@claude-plugins-official

Listed in Anthropic's official plugin marketplace.

Sourcegithub.com/supabase-community/supabase-plugin
security

3. Strix

in one lineAttacks your app like a hacker, then helps you fix the holes.
What it does

AI agents that test your app the way an attacker would, find security holes and help you fix them. Needs your own LLM API key. Only run it on an app you own.

Install
curl -sSL https://strix.ai/install | bash
strix --target ./app-directory             # first scan

Before the first scan, set STRIX_LLM and LLM_API_KEY (see the README). The first run pulls a Docker image.

Sourcegithub.com/usestrix/strix
design

4. SkillUI

in one lineCopy any site's design system into markdown.
What it does

Reverse-engineers a website's design system (colors, fonts, spacing, components) into markdown files Claude can read. Open source (MIT).

Install
npm install -g skillui
skillui --url https://yoursite.com --mode ultra  # point it at a site
Sourcegithub.com/amaancoderx/skillui
docs

5. Context7 (Upstash)

in one lineThe latest library docs, straight into your coding assistant.
What it does

Feeds your coding assistant up-to-date docs for the libraries you use, so it stops writing code for old versions.

Install
npx ctx7 setup

Signs you in and installs the skill or MCP mode. Add --claude to target Claude Code. Needs Node.js 18+.

Sourcegithub.com/upstash/context7
